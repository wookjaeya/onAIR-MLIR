검토서의 완료 기준: *"모델마다 새 임시 하네스를 만들지 않고 같은 정적 f32 단일 입력·출력 경로에서
완료된다."*

| 도구 | 이번 변경 |
|---|---|
| `harness/tflite_oracle.py` | **무변경** — 형상을 모델에서 읽고 있었다 |
| `harness/iree_runner.py` | **무변경** — 형상을 fixture에서 읽고 있었다 |

**모델별 분기(`if model == "deepae"`)는 한 줄도 없다.** 모델 규약은 전부 **값**으로 들어간다.

`--layout none`에서 원본 텐서와 엔트리 텐서는 **같은 파일**을 가리키고 해시도 같다 — rank-2
autoencoder에는 변환할 레이아웃이 없으므로 그것이 사실이다.

## 3. argmax — 예고한 것은 안 나왔고, 더 나은 것이 나왔다

계획서 §1은 *"DeepAE에 argmax를 요구하면 정직한 autoencoder를 거부하는 유형 (B) 과잉 거부가 될
것"*이라고 예고했다. **예고는 확인되지 않았다.** argmax를 요구한 채 돌려도 DeepAE는 **34/34 일치**로
통과한다. 예측이 맞지 않았으므로 그대로 적는다.

**대신 관측이 더 강한 근거를 줬다.**

| 모델 | 34개 입력에서 나온 서로 다른 argmax 값 |
|---|---|
| B2 ResNet | `{0, 4}` — 입력에 따라 변한다 |
| **B3 DeepAE** | **`{261}`** — **모든 입력에서 같은 칸** |

DeepAE의 argmax는 **상수**다. 34/34 일치는 두 구현이 같다는 증거가 아니라, 그 통계가 **변별력이
0**이라는 뜻이다. 검토서 §9.3이 *"DeepAE에는 분류 모델의 argmax 기준을 적용하지 않는다"*고 한
이유가 이것이며, 이제 그것은 지시가 아니라 **측정된 사실**이다.

그래서 `--argmax not-applicable`은 **모델 성질의 선언**이지 임계값 완화가 아니다. 불일치를 용서하지
않으며(`am_ok`는 `None`이지 `True`가 아니다), 기본값은 `require` 그대로다.

## 4. 음성 대조 — PASS가 의미를 가지려면 기준이 실패할 수 있어야 한다

ResNet에 NHWC 텐서를 **전치 대신 reshape**해서 넣었다(의도적으로 틀린 레이아웃).

| 항목 | 값 |
|---|---|
| 판정 | **FAIL** |
| 실패 원소 | **258 / 340** |
| 실패 샘플 | 32 / 34 |
| **argmax 일치** | **34 / 34 (100%)** |
| 원소 기준이 못 잡은 샘플 | `edge_zeros`, `edge_ones` — **상수 입력 2개뿐** |

**E31의 두 교훈이 다른 모델에서 재현됐고, 하나는 더 선명해졌다.**

1. **argmax 단독 판정은 위험하다.** E31은 SmartCam에서 잘못된 레이아웃을 argmax가 **92%** 통과시킨다고
   측정했다. ResNet에서는 **100%** — 34개 전부다. 틀린 레이아웃에서도 최대 칸이 그대로였다.
2. **경계 입력만으로는 레이아웃 오류를 잡을 수 없다.** 통과한 2개는 정확히 상수 입력이다.
   상수 배열은 어떤 재배치에도 불변이므로 **원리적으로** 못 잡는다. E31과 정확히 같다.

즉 이 실험의 PASS가 의미를 갖는 근거는 **비상수 합성 입력 32개**이지 경계 2개가 아니다.

## 5. 의미 검증의 등급 — 낮춰서 기록한다

검토서 §10 단계 4: *"실제 데이터가 없는 셀은 의미 검증 미완료로 남긴다."*

| 모델 | 입력 | 등급 |
|---|---|---|
| SmartCam(E31·E32·E33) | **실이미지 3** + 합성 32 + 경계 2 | 실데이터 포함 |
| B2 ResNet | 합성 32 + 경계 2 | **합성 전용** |
| B3 DeepAE | 합성 32 + 경계 2 | **합성 전용** |

CIFAR-10 평가셋과 ToyADMOS 오디오는 이 환경에서 조달할 수 없다(E26a가 이미 확인). 따라서 두 모델에
대해 **정확도는 주장하지 않는다.** 이 실험이 묻는 것은 *두 구현이 같은 계산을 하는가*이지
*그 계산이 맞는가*가 아니다.
