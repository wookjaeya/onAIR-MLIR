# EVIDENCE v0.75.2 — D113 기록 확장: 원고 v38이 심사 의견에 답하려고 더하는 두 사실의 근거

**경위**: 원고 v37의 종합 심사(메타리뷰 v37)가 두 가지를 물었다. (1) 평가한 비행 응용은 모듈 이미지를 늘 64바이트 경계에 두므로 copy 분기는 시험용 오프셋으로만
나타났다 — 정렬을 요구하지 않는 적재 경로가 실제로 copy 분기를 탄 적이 있는가. (2) 할당 대응 $K$의 근거가 피크 일치뿐이다 — $I$·$O$·$T$·$C$ 밖의 HAL 할당이
없었다는 근거가 있는가. 둘 다 **보관 원자료에 이미 답이 있었고** 원고가 인용하지 않았을 뿐이다. 원고에 문장으로 넣기 전에 그 사실을 저장소가 매번 다시 유도하도록
`records.json`에 두 항목을 더한다(D113·D77 방식). **새 실행 0, 평가 수치·판정 불변.**

## 1. 이전 빌드의 copy 분기 (`earlier_build_copy_arm`)

- **적재 코드**: 비행 응용은 `c086593`(E29) 전까지 모듈 버퍼를 `malloc`으로 잡았고 정렬을 요구하지 않았다. `77a2df1`:196 `g.blob = g.blob_len > 0 ? malloc((size_t)g.blob_len) : NULL;`,
  `e4c6371`:281 `g.blob = malloc((size_t)g.blob_len);`. `c086593`이 `posix_memalign(&p, 64, n)`과 `map_branch` 레코드(모듈 주소 mod 64·append 직후 할당)를 함께 넣었다.
- **게스트 셀 6개**(AArch64 QEMU 시스템 게스트의 cFS, 같은 컴파일러·런타임 리비전 `e4a3b04`), 개발용 모델 4종:

| 로그 | 모델 | 응용 소스 | HAL 피크 | $B_u$ ($P$ + $C$) |
|---|---|---|---|---|
| `e14_aarch64_qemu/cfs/logs/A1_conv2d.log` | conv2d | 77a2df1 | 3,528 | 3,528 (1,352 + 2,176) |
| `…/A1_multibranch.log` | multibranch | 77a2df1 | 38,216 | 38,216 (840 + 37,376) |

  - 6/6이 피크 = $B_u$이고 $C > 0$이므로 상수 블록이 할당됐다(copy 분기). canonical 두 셀은 추론 0회 시점 `mem_init`의 누적 할당이 이미 $C + I$ = 720,932였다.
  - **주소는 기록되지 않았다**(그 레코드는 정렬과 함께 들어왔다). 분기는 피크에서 **추론**한 것이다.
- **같은 malloc 코드의 user-mode 단독 실행**(비행 응용 아님, 시스템 게스트 아님) 14개: map 9 · copy 5. 같은 multibranch 아티팩트가 빌드에 따라 두 분기를 모두
  탔다 — 분기는 malloc 자체가 아니라 **버퍼가 놓인 자리**를 따랐다. 기록에 함께 싣는다(원고 문장이 *"일반 힙 할당이면 copy"*로 읽히지 않게 하는 근거).
- 네 공개 모델의 malloc 시기 셀은 **없다**.

## 2. 누적 할당 항등식 (`cumulative_allocation_identity`)

- **셀**: 원고가 세는 승인 실행 셀 37개와 정렬 셀 32개(목록은 `harness/e66_plugin_document_rules.py`의 `EXECUTION`·`ALIGNMENT`, 69개). 전부 AArch64 게스트 비행 응용.
- **필드**: `mem_init.hal_allocated`(정수)와 `mem.hal_bytes_per_call_amortized` = `device_bytes_allocated / 루프 호출 수`(`%.1f`, `ai_learner.c`).
  재생 블록 호출(`e25_equivalence.completed`)은 같은 할당자를 쓰지만 분모에 없으므로 기대값에 더한다.

| 호출 보고가 있는 셀 | 57 |

- **한계**: 바이트 합계이지 버퍼 단위 대조가 아니다. 이 카운터는 세션 할당자의 장치 메모리 카운터(보고된 피크와 같은 카운터)이고, 호스트 전용 할당과 가져온(import)
  버퍼는 여기에 없다 — 명세 범위 $S$의 정의(HAL 할당자 통계가 세는 할당)와 같은 경계다.

## 4. 주장하지 않음

- 이전 빌드에서 **모듈 이미지 주소가 64의 배수가 아니었음을 관측했다**고 쓰지 않는다 — 기록되지 않았고, copy 분기는 피크에서 추론했다.
